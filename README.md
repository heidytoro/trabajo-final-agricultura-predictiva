# trabajo-final-agricultura-predictiva
Entrenamiento de modelos de machine learning con datos reales y sintéticos
## datos
- Presultados_de_Análisis_de_Laboratorio_Suelos_en_Colombia.csv: base de datos descargada de agrosavia de https://www.datos.gov.co/Agricultura-y-Desarrollo-Rural/Vista-Agrosavia-Municipio-Funza/x54s-e9nd/about_data
- caña_panelera_s.csv: base de datos filtrada de la original solo por el cultivo caña de azucar.

## Notebook Colab
Preparacion de la base de datos: notebook donde se limpiar y organizan las características para el modelo.
Datos sintéticos: el notebook con los modelos de machine learning con los datos sintéticos.
Entrenamiento modelos con datos reales: notebook donde se entrenan los modelos de machine learning con los datos reales preprocesados.

## Documentos
- Presentación de la comparación de los diferentes modelos  con los dos tipos de datos.
- Artículo con introducción, metodología, resultado, análisis y conclusiones sobre el trabajo.
